# Story E4-S2: Payout Calculation with Financial Invariants

**Epic:** E4 (Assessment & Adjudication)  
**Story ID:** E4-S2  
**Title:** Implement payout calculation with financial invariants

---

## Description

The system calculates the final payable amount from a claim using deterministic, fixed-point arithmetic. The calculation enforces the Financial Invariant Rule (AC-05): `payable_amount = min(claim_amount, sum_insured) - deductibles - co_pay`, with the invariant `payable_amount >= 0` always maintained. The calculation is immutable and auditable.

---

## Acceptance Criteria

1. **AC1:** Payout calculation accepts: claim_amount (decimal), policy sum_insured (decimal), deductible (decimal), co_pay_percent (decimal), and claim type.

2. **AC2:** Formula: `payable_amount = min(claim_amount, sum_insured) - deductible - (min(claim_amount, sum_insured) * co_pay_percent / 100)`.

3. **AC3:** All arithmetic is fixed-point with at least 2 decimal places (no floating-point rounding).

4. **AC4:** If calculated payable_amount < 0, it is clamped to 0.0 (the invariant `payable_amount >= 0` is absolute).

5. **AC5:** Calculation returns: `assessed_amount` (before deductions), `payable_amount` (final), `deductible_applied`, `co_pay_applied`, and `reason_code` (e.g., "FULL_COVERAGE_ASSESSED", "PARTIAL_COVERAGE_CLAMPED", "ZERO_PAYABLE").

6. **AC6:** Calculation is deterministic and idempotent: same inputs always produce same output.

7. **AC7:** No intermediate rounding is allowed; all calculations preserve precision until final result.
